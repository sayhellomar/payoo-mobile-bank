# Payoo App

This project is a fully functional JavaScript digital wallet application designed to replicate real-world financial operations. Users can log in, manage their wallet balance, and perform various money-related actions. Core features include:

💰 Wallet Operations

**Add Money:** Increase your balance with input validations

**Cashout:** Withdraw funds with proper limit checks

**Transfer Money:** Send money to other users instantly

**Bonus System:** Earn rewards with specific coupon code

🧾 Payments & Records

**Bill Payment:** Pay predefined bills and reduce your balance

**Transaction History:** Every action is recorded with type, amount, date, and updated balance

This project demonstrates strong knowledge of JavaScript DOM manipulation, event handling, form validation, modular code structure, and dynamic UI updates.


## Tech Stack

**Client:** HTML, CSS, TailwindCSS, JavaScript


## Run Locally
